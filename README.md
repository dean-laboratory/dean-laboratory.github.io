# dean-laboratory.github.io

Dean Laboratory 의 조직 사이트 (GitHub Pages: https://dean-laboratory.github.io/).

- `app-ads.txt`: AdMob 앱 광고 판매자 확인 파일. 광고 크롤러가 Play 스토어의 개발자 웹사이트 도메인 맨 위에서 찾으므로 이 저장소(도메인 루트)에 둔다
- `index.html`: 앱 목록과 개인정보처리방침 링크
- 앱별 개인정보처리방침은 각 저장소의 Pages 에 있다 (예: https://dean-laboratory.github.io/pagora-privacy/)
